# BookMind

BookMind는 독서 후 내용을 오래 기억하고 실제 활용까지 연결할 수 있도록 돕는 AI 기반 독서 기억 관리 프로젝트입니다.

## 📖 사용 설명서 (아무것도 몰라도 괜찮아요)

### BookMind가 뭐 하는 앱인가요?

책을 읽고 나면 시간이 지날수록 내용이 흐릿해지죠. BookMind는 그 내용을 **오래 기억하도록 도와주는 개인 독서 도우미**입니다. 책을 등록하고, 느낀 점을 적고, 퀴즈를 풀고, 필사를 하다 보면 자연스럽게 내용이 머릿속에 남게 됩니다.

### 화면 아래 6개 탭이 전부예요

| 탭 | 여기서 하는 일 |
|---|---|
| 🏠 홈 | 오늘 뭘 하면 좋을지 한눈에 보여줌 |
| 📚 책 | 읽고 있는/읽은 책을 등록하고 관리 |
| 🧠 복습 | 책별로 얼마나 기억하고 있는지 확인 |
| ✍️ 기록 | 독서 노트, 독후감, 필사 연습 |
| ❓ 퀴즈 | 내가 등록한 책 내용으로 만든 퀴즈 풀기 |
| 👤 마이 | 통계, 테마(라이트/다크), 데이터 백업 |

### 처음 시작할 때 (1분이면 끝나요)

1. 하단 **📚 책** 탭 클릭 → **+ 책 추가** 버튼 클릭
2. 책 제목을 입력하고 **🔍 검색** 버튼을 누르면, 실제 책 정보(저자, 카테고리 등)가 자동으로 채워져요. (직접 입력해도 됩니다)
3. 읽기 시작한 날짜, 상태(읽는 중/완독)를 선택하고 **저장**
4. (선택) 내가 합법적으로 가진 책 PDF·TXT 파일이 있다면 업로드해두면, 이후 퀴즈와 필사가 훨씬 정확해져요

### 책을 읽으면서 할 일

- **✍️ 기록** 탭에서 오늘 읽은 핵심 내용, 인상 깊은 문장, 내 생각을 적어보세요.
- 다 적었으면 **🎯 피드백** 버튼으로 AI의 조언을 받을 수 있어요. 책 원본 파일을 올려뒀다면, 내가 잘못 이해한 부분이 있는지도 비교해줍니다.

### 독후감 쓰기 (부담 갖지 마세요)

1. **기록 → 독후감 작성**에서 책을 고르고, 내 생각을 자유롭게 적어요 (최소 50자).
2. **✨ AI와 함께 다듬기**를 누르면:
   - 어떤 부분이 책 내용과 맞는지/다시 확인이 필요한지 알려주고
   - 내 문체는 최대한 살려서 다듬어주고
   - 참고할 수 있는 모범 감상문도 보여줘요
3. 마음에 들면 저장하거나, 다른 사람에게 공유(복사)할 수 있어요.

### 필사 연습 (손으로 다시 써보기)

1. **기록 → 필사 연습**에서 책을 고르고 **📖 새 문장 가져오기**
2. 주어진 문장을 그대로 따라 입력해보세요. 오타는 빨간색으로, 진행률과 글자 수도 실시간으로 보여줘요.
3. 제출하면 정확도(%)와 함께, 방금 쓴 내용을 기억하는지 확인하는 짧은 질문도 나와요.

### 퀴즈 풀기

- **❓ 퀴즈** 탭에서 내가 등록한 책을 골라 퀴즈를 시작하세요.
- 문제 아래에 "이 문제가 책의 어떤 부분을 근거로 만들어졌는지"도 함께 보여줘서, 찍기가 아니라 확인하며 풀 수 있어요.

### 기억이 얼마나 남았는지 확인하기 (🧠 복습 탭)

전체 기억률뿐 아니라 **줄거리 / 등장인물 / 세부내용 / 핵심개념**을 항목별로 나눠서 보여줘요. 어디가 약한지 알면 그 부분만 다시 복습하면 됩니다.

### 마이페이지에서 할 수 있는 것

- 📊 지금까지 등록한 책, 작성한 노트, 완료한 퀴즈 통계 확인
- ☀️/🌙 라이트·다크 테마 전환 (눈이 편한 걸로)
- 📥 데이터 내보내기(백업) / 📤 불러오기(복원) — 기기를 바꿔도 데이터를 옮길 수 있어요

### 자주 묻는 질문

- **Q. 회원가입이 필요한가요?** → 아니요. 브라우저에 데이터가 저장되는 방식이라 로그인 없이 바로 씁니다. (단, 같은 브라우저에서만 데이터가 유지돼요)
- **Q. 책 파일을 꼭 올려야 하나요?** → 아니요. 안 올려도 직접 입력한 내용으로 퀴즈·독후감 기능을 쓸 수 있어요. 다만 실제 책 내용과 다를 수 있다는 안내가 함께 표시됩니다.
- **Q. 데이터가 사라지면 어떡하죠?** → 마이페이지에서 주기적으로 "데이터 내보내기"를 눌러 백업 파일을 보관해두세요.

## 문제 정의

많은 사람들이 책을 읽은 후 시간이 지나면 내용을 쉽게 잊어버립니다. 
그 결과 독서를 해도 내용을 오래 기억하거나 실제 과제, 독후감, 프로젝트에 활용하기 어려운 문제가 발생합니다.

## 핵심 기능

1. AI 기억 복습 시스템
- 읽은 내용을 주기적으로 복습하도록 개인화된 복습 타이밍 제공

2. AI 독서 퀴즈 생성
- 책 내용을 기반으로 퀴즈를 자동 생성해 이해도와 기억 정착 강화

3. AI 독서 노트
- 핵심 내용, 인상 깊은 문장, 느낀 점을 구조적으로 정리

4. 기억률 분석
- 사용자별 기억 유지 수준을 시각화하고 취약 영역을 진단

5. AI 독후감 도우미
- 사용자가 먼저 독후감을 작성하면, AI가 문장/표현/구조를 다듬어 모범 감상문으로 개선

6. AI 필사 지원
- 사용자가 원하는 책의 문서/PDF 파일을 불러와 필사 연습을 진행하고 저장

## 기대 효과

- 학생뿐 아니라 다양한 사용자들이 독서 내용을 오래 기억할 수 있습니다.
- 책의 핵심을 파악하는 방법을 익혀, 나중에는 앱 없이도 스스로 내용을 정리하는 습관을 형성할 수 있습니다.
- 책 내용을 기반으로 한 독후감상문, 수행평가, 프로젝트를 더 효과적으로 수행할 수 있습니다.
